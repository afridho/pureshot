# Settings title button

These SVGs are copied unchanged from the user's Zen customization:
`chrome/mactahoe-titlebuttons/titlebutton-close{,-hover,-active}-dark.svg`.

That customization attributes the artwork to `vinceliuice/MacTahoe-gtk-theme`
(MIT). The normal, hover and pressed artwork is kept at its original 16×16 size.
Only the settings window uses these assets; the control still minimizes PureShot.
